# 7StudySpace 第一版验收

2026-10-04。本次实现为 React + TypeScript + Vite 的可运行私人学习应用；没有公网部署。测试数据在 `/private/tmp/study77-qa-20261004`，正式预览数据在项目 `data/`。正式预览的记录页已核对三个统计均为 0。

## 功能验证

- `npm run build` 通过，前端主包约 100 KB gzip；图片、词库、课程、音频、OCR 资源均在本项目内，不依赖浏览器访问海外 CDN。
- 37 项前端数据/AI 测试通过：重复事件去重、复习安排、跨设备字段合并、旧稿保留、备份校验、CSV 引号和换行、MIME 规范化、AI 已完成请求处理、失败后的周复盘节制重试。
- 10 项服务测试通过：首次初始化、配对码一次性/过期、鉴权与同源保护、并发版本冲突、队列状态、附件范围下载。
- 课程校验通过：380 项、260 道选择题、无重复正文、选项与答案有效、证据在原文中、40 条音频哈希与非静音检查。
- npm audit：0 个已知漏洞。

Codex 内置浏览器（IAB）实际操作：

1. 单词先回忆、显示释义与例句、自评；刷新后继续第 2 张卡。
2. 阅读选择三题、保存笔记、刷新、提交；记录页显示实际 3/3 与原文依据。
3. 播放 33.72 秒音频、切换 0.75 倍速、设置片段起止并回到起点。
4. 关闭测试服务后刷新，打开未访问的另一段听力，离线实际播放 31.11 秒音频。
5. 导入 2 个 CSV 词条，编辑释义；空释义被阻止，返回调整保留修改；词条进入正式单词库。
6. 导入测试 PNG，识别三句英文并显示可编辑校对页；原件保留。
7. 导出 JSON 备份，文件包含 2 次学习事件、2 个导入词条、1 份资料和 2 个有效原件；通过界面恢复后仍只有原来的 2 次学习事件。IAB 的下载事件等待接口超时，但文件实际落在 Downloads；随后读到完整文件并实际恢复成功。
8. 学习搭子经本机 Codex 真实解释文章中的 trial；生成根据两次实际记录的复盘，明确样本不足；采用建议、刷新、撤回后恢复均衡安排。
9. 一次性配对经界面完成，显示已同步到私人学习空间。

尚未在实体 iPhone/iPad 的 Safari 上验收，未验证国内公网连接；PDF 文本/扫描识别已有实现与校对入口，本轮实际 OCR 交互使用 PNG，未把 PDF 端到端实测算作已通过。

## 视觉对照

概念：`design/home-concept.png`（1484×1060）与 `design/practice-concept.png`（1024×1536）。使用 IAB 截图，并使用 view_image 同时检查概念图与最终实拍。按 1484×1060 的原图视口检查，浏览器滚动条占 15px；另检查 390×844 手机、820×1180 iPad 竖屏与1180×820 横屏。手机内容宽度与可见宽度相同，没有横向溢出。

| 对照项 | 概念依据与实拍结果 | 修正或有意差异 |
| --- | --- | --- |
| 文案与导航 | 今天/学习/复习/记录、主标题、10/40/70 分钟、主按钮一致 | 日期使用北京时间；保存状态与继续入口来自真实状态 |
| 首页结构 | 左侧白色学习面板，右侧植物插画，下方开放式学习方向 | 手机为单列，插画移到主操作下方 |
| 字体 | 中文衬线标题、清楚的无衬线控件，英文单词用 Georgia | 手机标题缩小并平衡换行；长单词允许安全换行 |
| 颜色与容器 | 纸白背景、鼠尾草选中态、深绿主按钮；薄边框与圆角一致 | 未保留早期为提亮文字添加的颜色蒙层 |
| 图片与文字 | 水彩绿叶、玻璃瓶、绿书、茶杯，保留同一素材 | 改为完整呈现并缩小置于文字下方；边缘 alpha 淡出融合，避免裁掉叶片或覆盖文字 |
| 手机单词卡 | 大词头、音标、朗读、回忆提示、绿色揭示按钮、学习搭子 | 增加“回忆英文”切换，支持拼写检索练习；真实例句来源可展开 |
| 控件与状态 | 统一 Lucide 细线图标、选中态、留白与分隔线 | 手机底部四导航方便触达；恢复/同步/错误有明确状态 |

首屏文案差异：仅有意增加“和学习搭子聊聊”（手机首页需要入口）以及真实保存状态；没有添加排名、连续打卡、虚构进度或空泛奖励。修复了早期手机标题孤字换行、主按钮过低、植物遮字和图片裁切。当前没有已知的内容裁切、横向溢出或不可操作的主按钮。设计已按上述有意适配差异完成视觉核对，不声称逐像素复制。
