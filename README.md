# 7StudySpace · 77 的学习室

为英语六级与考研英语一准备的私人学习空间。用 React、TypeScript 和 Vite 制作，提供适合手机和 iPad 的阅读与操作界面；从今天能学的一点开始，保存过程，也允许随时停下。

## 可以做什么

- 按 10、40、70 分钟选择今日安排，继续上次进度；没有排名、连续打卡惩罚或催促。
- 学习词汇、听力、阅读、长难句、写作和翻译；先尝试回忆，再查看答案、原文依据或参考表达。
- 保存答案、草稿、笔记、听力位置和学习记录，安排词汇复习；学习记录按北京时间展示。
- 导入文字、PDF、图片及音频，整理自己的资料；图片 OCR 后可人工校对。
- 配对设备、合并学习记录、导出完整备份；可选学习搭子与周复盘，建议由本人决定是否采用。
- 逐题作答、答题卡跳转、漏答定位、错题解析和连续下一篇；暂停后从原组继续，完成后看本组小结。
- GitHub 式近 52 周学习格子，完成练习自动留下记录；点选日期查看当天练习，比较上一次学习日的题量和正确率，不计算连续打卡天数。

每天的词汇回忆与客观题成绩分别统计，正确率以实际答对题数除以作答题数；重做会明确标出，题目难度或题量不同的结果仅供观察。本组小结取每篇在本组内最近一次作答，历史页保留每次尝试。

## 历年真题资料架

“学习 → 历年真题”直接展示当前私人空间内能开始练习的 **6 套试卷**：六级 2023 年 12 月、2024 年 6 月、2025 年 6 月第一套，以及考研英语一 2023、2024、2025 年。真题可以进入每日安排，站内逐题作答并连续练习；原卷与机构参考答案作为单独附件保留，也可以逐页阅读、保存笔记。

已整理 **18 篇阅读、90 道选择题，以及 10 项写作/翻译任务**：六级每套 2 篇阅读、1 项作文和 1 项翻译；考研英语一每年 4 篇阅读，另有 2023 年小作文、2025 年完整翻译及大小作文。自由作答保存草稿与学习记录，不生成客观题分数；2025 年大作文表格已完整转为带单位的文字数据，可直接据此写作。

阅读题文和选项对照原卷图版核对，答案保留机构来源；考研英语一另做第二来源核对，并披露 2023 年第 33 题、2024 年第 34 题的机构版本差异。2025 年英语一曾有漏段的早期版已弃用。**听力、完形等未结构化部分目前仍需阅读原卷，六级原卷音频尚未导入**，不能视为整卷在线考试。研究阶段核实的 19 套历年卷与 1 份官方样卷目录保留在数据和文档中，不再作为界面上的外链列表。完整证据、核验方法与范围见 [真题资料来源](docs/exam-sources.md)。

原卷、机构参考答案与结构化真题只保存在私人资料中，不放进 `public/` 或公开源码，也不随应用构建再次分发。机构参考答案不标为官方答案；这些私有资料不计入下方原创课程数量。

换浏览器后若只看到 **380 份**，这是内置练习数量，私人真题尚未同步。各浏览器的连接与本机保存互相独立；在资料页选择“连接私人学习室”，通过已有浏览器的配对码连接后会合并记录，当前私人空间共有 **408 份可练资料**。若页面提示请求来源不一致，请检查跨域或请求头修改扩展是否改写了本机站点请求，再重试同步；不要清除浏览器里的学习记录。

导入会分离文章、题目和参考答案，支持逐题答案或末尾集中答案键。未识别的题目会提示核对，完整粘贴原文另存为 TXT 附件；每份最多 100 道交互题。保存前验证格式，重练保留旧答案记录与历史草稿。

复习安排是可调整的产品规则，不代表个人记忆的精确预测；AI 讲解与参考答案也需要判断和核对。

### 所有者批量导入原卷

先准备原卷 PDF、单独的参考答案 PDF 和私有 JSON 清单，再在服务所在电脑运行：

```sh
node scripts/import-private-exams.mjs --manifest /绝对路径/exams.json --data-dir /绝对路径/data
```

`--data-dir` 必须与服务实际使用的私人数据目录一致。清单格式、备份行为和校验限制见 [私有导入说明](docs/exam-sources.md#所有者私有导入脚本)。脚本保留已有学习记录，重复导入同一试卷会跳过；它只导入原卷及参考附件，不会自动把 PDF 转成可判分题目。

词汇例句中 **435 组为原创、1,443 组来自 Tatoeba**。社区例句经过筛选及抽查，尚未逐条完成专业审校。词库面向通用与学术英语基础，不声称是完整官方考纲。词义、频率与例句的来源、逐项归属及许可见 [词库来源说明](public/content/vocabulary-sources.json)；词条保留具体例句链接。原创例句采用 CC BY-SA 4.0；Tatoeba 内容分别保留 CC BY 2.0 France 或 CC0 等原始许可，不能统一视为无版权素材。

## 本机运行

需要 **Node.js 22.13 以上的 22.x 版本**及 npm。

```sh
npm ci
npm run dev
```

打开终端显示的前端地址。开发模式同时启动前端和私人数据服务，首次仅允许本机自动初始化空间。

运行构建后的完整应用：

```sh
npm run build
npm start
```

访问 `http://127.0.0.1:4174`。`npm start` 同时提供构建后的前端和 `/api`；`npm run preview` 仅用于前端预览，不能代替完整服务。

## 手机、iPad 与云端部署

项目支持 Vercel：前端由 CDN 提供，`api/index.mjs` 提供同源接口，状态和附件存入 **Private Vercel Blob**。生产环境使用香港区域。SQLite 继续用于本机开发，生产函数不写临时 SQLite。

每台浏览器首次通过一次性配对码连接同一私人学习室。连接后可获取已迁移的真题和学习记录；未配对访客只能使用内置原创资料。配对码由已连接设备在“设置 → 配对另一台设备”生成，10 分钟内有效。线上和本机地址各自保存浏览器数据，需要分别连接。

部署与迁移步骤见 [Vercel 部署说明](docs/deployment.md)。大陆网络可达性取决于实际网络环境，尚未在国内真机验证。添加到主屏幕与离线使用，需要首次联网打开并完成资源缓存。

## 可选的 Codex 学习搭子

Vercel 云端当前尚未连接本机 Codex 工作端，AI 请求会明确显示暂不可用；不会上传 Codex 登录凭据或生成伪回复。本机版本的 AI 默认关闭。由持有本人 Codex 登录的空间所有者，在运行服务的 Mac 上显式启用工作端：

```sh
STUDY77_CODEX_WORKER=1 npm start
```

正式服务也需保留前面的 `NODE_ENV`、`STUDY77_PUBLIC_ORIGIN` 配置。可用 `STUDY77_CODEX_BIN` 指定本机 Codex 程序。工作端锁定已验证的 **Codex CLI 0.156.1**，版本不匹配时自动关闭；升级不能直接视为兼容。

Mac 和服务需要保持在线，工作端也要可用，才能处理 AI 请求。服务可达但工作端关闭或不可用时，任务会保存并明确显示不可用；启用后重新排队，不提供伪造的 AI 回复。本人登录、订阅使用资格和目标环境需单独核实。受限运行方式及本机验证范围见 [工作端安全边界](server/README.md#本机-codex-工作端的安全边界)。

## 离线、同步与备份

生产构建注册 PWA Service Worker。**首次联网打开并成功完成缓存后**，前端、内置课程、词库、图片和全部内置听力音频可以离线使用。OCR 资源按需加载，首次识别需要联网，下载后才进入缓存。同步和 AI 仍需要网络；浏览器清理站点数据也会清除本机缓存。

学习状态和导入原件先保存在浏览器 IndexedDB。已连接私人空间时可同步到服务器；草稿和笔记发生不同版本冲突时保留副本供核对。

- 在设置中使用“导出备份”，将 JSON 文件保存到设备的“文件”或其他可靠位置。备份包含学习记录、笔记及本机保存的原始资料。
- 使用“选择备份恢复”导入学习室导出的完整 JSON；恢复会合并现有记录。尚未保存在该设备上的原件不应假定已包含在备份中。
- 服务器数据默认位于 `data/study77.sqlite`，原件位于 `data/files/`。用 `STUDY77_DATA_DIR` 指定其他持久目录。备份整个服务前先停止服务，或使用 SQLite 在线备份；运行时只复制主数据库文件可能遗漏 WAL 中的数据。

## 检查

```sh
npm test
node --test tests/private-exams.test.mjs
npm run build
python3 scripts/build-curriculum.py --verify
```

`npm test` 运行前端逻辑与服务测试；私有原卷导入另有 7 项测试，使用上面的独立命令运行。课程验证需要 Python 3，会重建课程 JSON 并检查数量、词数、重复、题目依据及现有音频文件。测试结果不等同于公网部署成功或真实 iOS 设备验收。

如果所有设备的浏览器会话都丢失，空间所有者可在保存数据的电脑上运行 `node server/pair.mjs`，生成十分钟内一次有效的恢复配对码；在设置中输入即可。已有学习数据保留，配对码不要公开分享。
